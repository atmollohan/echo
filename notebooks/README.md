# Notebook Guide

Current notebook naming:

- `library_plate_a_protocol.ipynb`
- `library_plate_b_protocol.ipynb`
- `premade_sensor_dual_antigen_protocol.ipynb`
- `dual_antigen_expression_protocol.ipynb`

These notebooks are currently self-contained workflow templates. They define their own
parameters inside the notebook and write Beckman Echo CSV outputs directly.

Historical reference outputs for the library plate workflows are stored in case folders under `data/raw/`:

- `data/raw/library_plate_a/20240813_ML_L1_source_plateA.csv`
- `data/raw/library_plate_a/20240813_ML_L1_echo_protocol_plateA.csv`
- `data/raw/library_plate_b/20240813_ML_L1_source_plateB.csv`
- `data/raw/library_plate_b/20240813_ML_L1_echo_protocol_plateB.csv`
